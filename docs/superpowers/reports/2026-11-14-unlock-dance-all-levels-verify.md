移除 `Game.setActivity` 和活动按钮的蹦迪关卡条件，更新入职手册、当前玩法说明与现有蹦迪测试。

## 检查结果

- `npm test` 通过 110 项测试。新增用例通过正常活动入口验证全部四关的蹦迪、准备期和收手时序。
- `npm run build:site` 成功生成 28 个运行文件。
- `git diff --check` 通过。
- 只读代码审查确认点击和数字键共用同一入口，按钮沿用暂停、弹窗、离座、锁定与收手条件，没有阻塞问题。

## 玩法观察

前两关各使用固定种子 1 至 30，持续选择蹦迪、被抓后继续的策略各通关 30 局。这说明当前自动收益规则允许低参与通关，后续交互玩法设计需要重新验证收益与目标。

用户进一步说明，希望在屏幕中真实操作摸鱼内容。后续讨论优先围绕可操作的小玩法展开。
