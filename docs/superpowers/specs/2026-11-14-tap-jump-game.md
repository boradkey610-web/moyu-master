# 点按跳障碍试版

用户已确认操作型摸鱼方向，并授权实现、实际试玩及更新开发机。窗口位于操作区，老板巡逻继续。

采用点击或上箭头跳跃、越障获得奖励的小玩法。首次等待点击，空格和绿色按钮继续执行收手。失误只清空小玩法连击并短暂恢复，让玩家可以继续判断老板风险。

运行状态由引擎时钟拥有，绘制层只读取。每次越障基础奖励为 4 至 8 金币，连续摸鱼与金椅沿用已有结算入口。打游戏的自动按秒收入转为越障收入。旧成绩与新规则分开，解锁进度继承。

验收覆盖首个输入、连续跳跃、碰撞、暂停、收手、换座、被抓、收益翻倍、存档迁移和静态资源完整性。实际浏览器操作检查能跳、能收、老板可见，至少完成一局及重试，并检查 375×667 布局。
