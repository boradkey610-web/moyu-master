# 整数金币和跑酷自动开始

用户明确要求所有金币不显示小数，点击打游戏直接开始。钱包、工资条、待领取金额、到账反馈和无障碍信息中的金币向下取整，失败差额向上取整。实际收入与胜负阈值保持内部精度；不足1的待领取奖金隐藏数字提示，到账不足1时只反馈文字，不出现+0。

进入打游戏直接跑动和推进障碍，不自动跳跃，首障从420px进入；停止、暂停、被抓、换座时仍使用现有引擎限制。移除等待首次输入的started字段与提示分支，更新模拟跳跃策略，不改收益/风险/罚款参数。

验证：整数边界测试、自动跑动/无输入无得分、计时冻结、跳跃/收手、左侧离场和四关30固定种子；375×667实际得分结算、失败页面、开发机资源校验。沿用现有分支，用户已选择保留且暂不归档。
