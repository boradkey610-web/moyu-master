# 办公室道具风格

用户已选择工资条、红印章、便签和手绘描边方向，并要求优化角色上方的奖金与声音提示。

结算复用现有 statement、activitySummary 和 processModal 调用路径，重组为单张工资条，使用主角肖像和现有活动 SVG。金额与操作行为继续读取当前游戏状态。共享标题改为便签页眉，样式限定在游戏内弹窗，首页与关卡入口继续使用已有展示。

角色上方取消百分比与待收金额混排，显示“收手领 X 金币”。声源明确区分键盘声、音乐声及传声范围，绘制声波图标。

验证覆盖金额、听觉阈值、成功失败结算、暂停、助力按钮和窄屏可访问性，实际浏览器检查后更新原开发机。

金额显示保留一位小数：钱包和工资条向下截取，未达标差额向上取一位，避免显示达标但实际未达标。游戏胜负判断保持使用实际金币。
