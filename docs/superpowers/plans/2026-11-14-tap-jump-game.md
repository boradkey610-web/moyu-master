# 实施计划

使用 executing-plans 执行，用户已授权实现并部署，采用当前隔离分支和直接编写后针对回归验证的方式。

1. 新增 `src/runner.js`，实现等待输入、跳跃、障碍、越障计分、碰撞恢复与读取状态的绘制。由 `Game` 管理活动切换、时钟及收益。添加回归并更新受收益规则影响的既有测试。
2. 在 `index.html`、`style.css` 和 `src/app.js` 接入操作区窗口。首次输入启动、点击与上箭头跳跃，绿色按钮和空格始终收手。同步静态白名单、构建检查、模拟策略与存档迁移。
3. 执行完整测试、构建和只读代码审查，实际浏览器试玩及小屏检查，修复观察到的问题。提交验证后的版本，生成静态发布包，上传原开发机新版本目录，逐文件校验后切换 `current`，记录发布结果和截图。
