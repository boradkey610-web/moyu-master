# 憋笑挑战实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将点击换段子改为“按住憋笑、松手喘气”的单手挑战，保留当前收入、检查与收手规则。

**Architecture:** 轮次、输入状态、结果和计时归属现有 `Game` 模拟；页面仅发送输入和读取状态。失败笑声复用现有声场、听觉和预测复制，固定在发声时座位；沿用现有控制区布局与原生事件，不新增模块或依赖。

**Tech Stack:** 原生 JavaScript ES modules、HTML/CSS、内联 SVG、Canvas、Node.js test runner。

用户已批准当前分支由主流程直接执行；遵循 TDD，保留分支、不归档、不推送。下列三组分别对应 `openspec/changes/joke-hold-laugh/tasks.md` 的 1.1、2.1、3.1。

### 任务 1：互动模拟与笑声契约（1.1）

**文件：** 修改 `src/engine.js`、`tests/joke-feed.test.js`、`tests/sound-source.test.js`；参考 `tests/risk-loop.test.js`。

1. 将已废弃的 `nextJoke` 用例改为挑战行为测试，先执行 `node --test tests/joke-feed.test.js tests/sound-source.test.js`，确认因缺少新行为失败。覆盖铺梗 1.2 秒、挑战 6 秒、结果 1.2 秒自动换条；初始笑意 18、气息 100；按住每秒 −30/−32，松手 +24/+50，均限于 0..100；笑意满或气息空立即失败，撑到结束成功。持续按住和完全不操作均不能成功。
2. 在已有活动生命周期与模拟步进中实现最少状态。以“挑战开始后按住 1 秒、松开 1 秒，重复三次”为成功测试输入；另测一直按住、一直松开、结果阶段重复步进。奖励只发一次，基础每秒收入保持；成功额外 3 金币、金椅翻倍，并按成功时现有连摸比例计入待收奖金。
3. 补充暂停/弹窗冻结、开始收手/换座/抓包释放、重新进入新轮、快速切换无法领奖的失败测试，再接入现有转换路径。不在 UI 另起计时器。
4. 失败发出一次强度 60 的固定座位笑声。由于 `hearSource` 只选择 active 声源，为短笑声保留约 1 秒 `burstUntil` 可听窗口，随后继续按原声场衰减；不重写已开始调查的 `lastHeard` 快照。测试附近实际听见、远处未听见、移动后仍查旧座、已有调查不改写、镜子预测复制不污染真实声场；笑声不能直接扣款或抓包。
5. 再运行上述命令及 `node --test tests/risk-loop.test.js`，期望全部通过；旧“段子始终无声”测试按新失败笑声语义调整，保留未失败时无声的断言。检查差异后同步 1.1。

### 任务 2：漫画窗口、输入与可读反馈（2.1）

**文件：** 修改 `index.html`、`style.css`、`src/app.js`、`src/render.js`；新增 `tests/joke-controls.test.js`，按现有 `tests/runner.test.js` 输入测试方式组织；扩展 `tests/render-motion.test.js` 中声音语义用例。

1. 先写输入回归：主指针按下/抬起，窗口外抬起，`pointercancel`/`lostpointercapture`，Enter 按下/松开和重复键，页面失焦释放；暂停/收手/离座不接受新按住。执行 `node --test tests/joke-controls.test.js`，确认旧输入实现失败。
2. 删除原点击换条输入；触摸和鼠标使用指针捕获，Enter 与它们调用同一模型输入入口，空格继续收手。只在真实输入边界处理取消和失焦，复用现有暂停及活动切换流程。
3. 在既有固定高度窗口内用内联 SVG 展示鼓腮/脸红/喘气及成功失败表情；两侧显示笑意、气息，文字提示“按住憋笑 / 松手喘气”。显示铺梗、挑战与结果，保留一键工作位置，不新增玩法切换或资源请求。
4. 将通知、检查者标签、声源图形和无障碍描述中的笑声统一为“笑声”，不得落入手柄声音分支；更新段子按钮的风险描述。补上对应语义回归。
5. 执行 `node --test tests/joke-controls.test.js tests/joke-feed.test.js tests/render-motion.test.js tests/runner.test.js`，期望全部通过。手机视口检查 375×667 及当前目标设备尺寸，确认控制区不跳位、表情与双条可读，收手按钮可操作；同步 2.1。
