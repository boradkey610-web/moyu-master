# 游戏内抓包演出素材

仅包含游戏运行所需的七张 PNG。老板、主角和背景来自 V4，生气女主管来自 V5，登记在 `assets/manifest.json` 的 `caught-*` 条目中。原生 Canvas 2D 合成，无 GIF 或视频运行依赖。

`src/caught-scene.js` 使用独立演出时钟。`src/engine.js` 在打游戏被抓时保留小游戏状态快照；`src/app.js` 将提醒与罚款弹窗替换为演出，在末尾等待回应。后台暂停、减少动态偏好、跳过、罚款及助力均保留。

本地查看 `/dev/caught-review.html`，可切换老板、主管、提醒和罚款。预览调用实际 app 和演出模块；调试入口不加入静态发布包。跳过仅快进到回应，不解除游戏暂停。刷段子与跳舞仍使用原有抓包弹窗。

发布构建通过 manifest 选择 PNG，本说明、生成参考、提示词、请求日志及 GIF 不进入 `dist/`。本轮没有推送或部署。
