# 设计

用户已通过选择题确认上滑刷段子＋双击点赞。DOM卡片放在现有控制区第一行，替代活动按钮，和跑酷/普通状态共享高度及工作按钮坐标。使用8条原创职场小段子，按索引循环，无网络请求。双击整张卡出现爱心并额外得1金币，每条只给一次；金椅时2金币。原基础2金币/秒与连摸奖金规则保持，点赞奖励也按当前档计入额外奖金。

Game持有post/liked/likes/reward/heartLeft，统一jokeAction(next/like)在输入边界判断暂停、模态框、活动、座位、移动、收手和锁定。切回工作保留该条已赞状态，避免反复进出领取。反馈随tick更新，暂停冻结。

app仅识别向上滑动和350ms内双击，横滑/取消不触发；键盘Enter点赞、↑换卡，空格仍一键工作。卡片用原生button和文本描述，屏幕阅读器激活也可点赞。工具栏道具、老板巡逻、全关卡开放、已有成绩及蹦迪无主动提醒保持。
