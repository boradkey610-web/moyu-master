# 设计

角色上方仅在已有待结算奖金时显示“收手领 X 金币”，金额来自 pendingBonus。音量从原有阈值读取，低于 40 显示暂未传出，40 至 75 表示附近可听见，75 以上表示远处也可听见。使用喇叭声波替代类似网络信号的柱形图。

结算采用工资条表现，主标题、红绿印章、角色插画、收入与目标、摸鱼流水印在同一张纸上。用撕边、虚线和票据按钮建立办公室物件感。暂停、帮助、教程、会议等采用夹板便签标题，被抓的角色对话沿用已有肖像。

保留收入、成绩、首警告、罚款、测试助力、重试和选关的原有逻辑。新元素放在现有 overlay/dialog 内，继续使用现有 inert、焦点和暂停路径。
