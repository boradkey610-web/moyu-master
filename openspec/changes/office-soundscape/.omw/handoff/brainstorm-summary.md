# Brainstorm Summary
- Change: office-soundscape

## 确认的技术方案
用户已明确选择按轻爵士/迪斯科/打印机持续声与秒数、统一静音方案实施并更新开发机。采用原生WebAudio合成原创循环，不引入依赖；沿用现有按钮和当前分支。
## 关键取舍与风险
内存PCM循环避免逐帧排音不稳定，音色与首次生成时间需实测；首次操作才创建Context，音频失败不阻断游戏。素材文件方案增加加载/版权管理，在线音乐方案增加网络依赖，均不采用。
## 测试策略
倒计时/暂停/周期、PCM有限值和电平、双场景切换不叠加、后台/开关/短音生命周期；真实手机浏览器状态与实际事件对应，资源摘要。
## Spec Patch
无。当前平台无程序化压缩机制；直接保留完整文件继续用户已授权实施，避免额外中断。
