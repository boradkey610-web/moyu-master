# 点按跳障碍

## ADDED Requirements

### Requirement: 打游戏通过实际跳跃得分

游戏 SHALL 在打游戏活动中展示操作区小窗口，成功躲过障碍才发放该活动收益。

#### Scenario: 等待输入

- **WHEN** 玩家进入打游戏但没有点击跳跃
- **THEN** 小玩法等待首次输入且没有打游戏收益，老板和关卡计时继续运行

#### Scenario: 跳跃得分

- **WHEN** 玩家跳过障碍
- **THEN** 发放金币与连摸奖励，金椅同时翻倍

#### Scenario: 收手与暂停

- **WHEN** 玩家收手或暂停
- **THEN** 小玩法停止计分，收手风险持续到工作完成，暂停冻结办公室和小玩法

#### Scenario: 办公室可见

- **WHEN** 小窗口显示
- **THEN** 窗口位于办公室画面之外，老板与一键工作持续可见
