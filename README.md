# 摸鱼大师

暖色漫画办公室中的竖屏摸鱼小游戏。原生 JavaScript + Canvas 2D，无第三方运行时依赖。

## 启动

安装 Node.js 22 或以上后，在本目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4178 。浏览器需要 JavaScript，不能直接双击 index.html（ES modules 需 HTTP）。手机样式自动适配；当前服务只监听本机，不对局域网开放。

## 玩法

- 选择看段子/打游戏/蹦迪：每秒1/3/6金币，蹦迪第三关解锁。
- 收手分别需要0.1/0.5/1秒；期间仍可能被抓。空格一键工作，数字1/2/3切活动，Esc暂停。
- 点击空椅子换工位。移动不赚钱；遇检查者出现可点击招呼剧情，期间全局暂停，回应后继续原路线。
- 每局首次抓包仅警告，三种活动有不同台词。后续每次扣50，负余额失败。
- 反光镜显示所有在场检查者未来10秒路线与停留点。开会通知支走一人，途中仍会检查。
- 金色工位持续24秒，所有摸鱼收益×2，到期恢复；道具坐下拾取，同事会争抢。
- 四关目标100/250/300/350，限时120/180/180/180秒。达标立即胜利。
- 本地保存关卡解锁、无助力与助力最佳成绩。浏览器存储不可用时仍可玩。

## 首版边界

这是可玩的浏览器版本。奖励入口明确标注为“测试奖励”，没有接入真实广告、账户或付费服务。没有发布到游戏CDN。场景、桌椅和角色采用本地插画素材，保留向量回退；参考提供图片的布局和暖色风格。

`src/engine.js` 管理关卡、收益、巡查、道具和双倍参数；`src/render.js` 负责绘画；`src/app.js` 管理UI和存档。双倍首次12秒出现、持续24秒、刷新间隔32秒；道具首次18秒、间隔28秒。这些属于初测配置，尚待真人试玩调平衡。

## 验证

```sh
npm test
npm run build
```

`build` 是无打包项目的语法检查。测试覆盖收入、收手、首次警告、罚款、冻结、预测、双倍、道路最短路、占座竞争、奖励和四关配置。
